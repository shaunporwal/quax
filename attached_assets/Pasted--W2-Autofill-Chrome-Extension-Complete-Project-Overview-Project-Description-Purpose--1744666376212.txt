# W2 Autofill Chrome Extension: Complete Project Overview

---

## Project Description
- **Purpose:** Create a Chrome extension that extracts data from W2 tax forms and automatically fills in online tax forms.
- **Target Users:** Individual taxpayers filing their taxes online.
- **Key Functionality:** 
  - PDF parsing
  - Data extraction
  - Form field detection and autofill
- **Privacy Focus:** Process W2 data locally with optional AI enhancement (OpenAI only)

---

## Technology Stack
- **Frontend:**
  - **HTML/CSS:** Simple popup interface with file upload and settings
  - **JavaScript:** Core extension functionality
  - **PDF.js:** Mozilla's PDF rendering and extraction library
  - **Canvas API:** For rendering PDFs as images when needed
- **AI Components:**
  - **OpenAI API (GPT-4.1 with vision capabilities):** For enhanced extraction
- **Development Tools:**
  - **Chrome Extension Developer Tools:** For debugging and testing
  - **Webpack/Parcel:** For bundling the extension code (optional)
  - **ESLint:** For code quality and style consistency

---

## Extension Components
- **manifest.json:** Extension configuration (permissions, resources, CSP)
- **popup.html / popup.css:** User interface for the extension
- **popup.js:** Main controller for user interactions
- **pdf.js:** PDF processing library plus custom extraction logic
- **content.js:** Content script for form field identification and filling
- **background.js:** Background script for persistent functionality (if needed)

---

## Key Functionalities
- **PDF Text Extraction:** Convert PDF to text or images using PDF.js
- **Data Parsing:** Extract W2 values using pattern matching or AI
- **Form Detection:** Identify form fields on tax websites
- **Field Mapping:** Match W2 data to the correct form fields
- **Settings Management:** Save user preferences and API key securely in Chrome storage

## W2 Tax Information

### Critical W2 Fields to Extract
- **Box 1:** Wages, tips, other compensation
- **Box 2:** Federal income tax withheld
- **Box 3:** Social Security wages
- **Box 4:** Social Security tax withheld
- **Box 5:** Medicare wages and tips
- **Box 6:** Medicare tax withheld
- **Employer Information:** Name, EIN (Employer Identification Number)
- **Employee Information:** Name, SSN (display only last 4 digits for privacy)
- **State Information:** State income tax and wages (Boxes 15–17)
- **Local Information:** Local income tax (Boxes 18–19)

### W2 Form Variations
- Different employer layouts (varied W2 formats)
- Government W2s with specific formats
- Multiple/combined W2s for individuals with several jobs
- Electronic versus scanned paper W2s

## Simplest Approach: W2 Extraction with GPT-4.1 Vision

### Core Concept
- Use PDF rendering to create images sent directly to GPT-4.1's vision API.
- Bypass complex text extraction algorithms with vision-based analysis.

### Key Components
1. **PDF Rendering Pipeline**
   - Convert PDF to a high-quality image using PDF.js.
   - Render the first page (containing key W2 data) to a canvas.
   - Convert the canvas to a base64-encoded image.
2. **OpenAI Vision API Integration**
   - Send the rendered image to GPT-4.1 with clear, precise instructions to extract W2 fields.
   - Parse the structured JSON response containing W2 data.
3. **Minimalist User Interface**
   - File upload control for W2 PDF selection.
   - API key input field.
   - Extraction button to trigger processing.
   - Results display area for extracted data.

---

## Workflow
1. **Input:**
   - User selects a W2 PDF file.
   - User provides an OpenAI API key (stored locally).
2. **Processing:**
   - PDF first page is rendered to an image.
   - The image is sent to GPT-4.1 with specific extraction instructions.
   - The API returns structured data with all W2 fields.
3. **Output:**
   - Extracted W2 data is displayed to the user.
   - Data is made available for autofill on online tax forms.

---

## Advantages
- **Simplicity:** Eliminates the need for complex text extraction algorithms.
- **Accuracy:** Vision models understand the visual layout of W2 forms.
- **Adaptability:** Works with various W2 formats (scanned, digital, different employer layouts).
- **Maintainability:** Reduced code complexity simplifies maintenance and debugging.

---

## Implementation Considerations
- **Performance:** PDF rendering happens on the client side before an API call.
- **Privacy:** Only the rendered image is sent to OpenAI; raw data remains local.
- **Cost Efficiency:** One API call per W2 form.
- **Error Handling:** Include fallbacks and error messages for API call failures.

---

## Chrome Extension Integration
- **Permissions:** Minimal requirements (e.g., file access, OpenAI API).
- **Architecture:**
  - All processing occurs in the popup interface.
  - Content script is used only for detecting form fields and autofilling data.
- **Storage:** Securely save the API key in Chrome storage for convenience.
